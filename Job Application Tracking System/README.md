# Job Application Tracking System

## Project Description
The Job Application Tracking System is a web application developed using Python and Django. It helps users manage and track their job applications in one place.

## Technologies Used
- Python
- Django
- SQLite
- HTML
- CSS

## Features
- User Registration and Login
- Add Job Applications
- View All Job Applications
- Edit Job Application Details
- Delete Job Applications
- Search Applications by Company Name or Job Role
- Filter Applications by Status
- Dashboard with Application Statistics
- View Upcoming Interviews
- User-specific Application Management

## Project Structure
- `applications/` – Main Django application
- `jobtracker/` – Project configuration
- `manage.py` – Django management file
- `website_images/` – Project screenshots

## How to Run the Project

1. Clone or download this repository.
2. Open the project folder in the terminal.
3. Install Django:
   `pip install django`
4. Run database migrations:
   `python manage.py migrate`
5. Start the development server:
   `python manage.py runserver`
6. Open `http://127.0.0.1:8000/` in your browser.
